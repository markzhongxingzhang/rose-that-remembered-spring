What this repository leaves out

This repository describes a research program. It does not reproduce the program. The following are deliberately not included:

  • source code for the simulated worlds, the instruments, the learners and the analyses;
  • model weights and any other trained artifact;
  • prompts, scene texts, item catalogues and other stimulus material;
  • raw model outputs, logs, run directories and internal ledgers;
  • details of the computing infrastructure: hardware, cluster and scheduler configuration, and credentials;
  • implementation details of the methods, beyond the high-level descriptions given here;
  • detailed experimental designs and protocols;
  • quantitative results: this version states results in words, and the figures are kept in the private record;
  • seeds, and the identity of the material reserved for confirmatory evaluation (publishing either would compromise that evaluation);
  • private correspondence, review discussions, and personal information about anyone.

Why

  • The work is ongoing. Its methods may still be developed, published or evaluated.
  • Sealed material must stay unseen. Material reserved for confirmatory evaluation has to stay sealed until it is used.
  • High level by design. Where a finding rests on a method that is not disclosed here, the method is described only by what it does.

The private research record

A detailed private record holds the full protocols, code, outputs and decisions behind every statement here. Each public statement was checked against that record before this version was prepared. The private record is not published, and publishing this repository does not publish it.

This repository contains no hidden content. The website uses no scripts, no analytics, no external fonts and no third-party requests.
