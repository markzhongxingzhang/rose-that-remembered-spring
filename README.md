# The Rose That Remembered Spring
### 一朵记得春天的玫瑰

*A literary-scientific research record. It asks whether an artificial agent's own past can change what it later does, and whether later life can change what that past means.*

**The Little Prince is our inspiration, not our answer key.**\
**《小王子》是我们的灵感，而不是实验的标准答案。**

The outcomes are not scripted. Positive, negative, null and unexpected findings are all scientifically acceptable.

---

## Where the research stands

Public record version 0.1.0. Content prepared 17 October 2026. The release date and commit are recorded in [integrity/RELEASES.md](integrity/RELEASES.md).

- **Development stage only.** Every result here comes from development studies in small simulated worlds. No confirmatory evaluation has been run. As of this version, the material reserved for confirmatory evaluation has not been used.
- **Latest step.** The most recent study closed on 12 October 2026 with the decision *revise*. A repaired instrument has been proposed but not authorized. No experiment is running.
- **The central question is open.** The project has not shown that an agent's *personal* history changes its later free choices. It has not tested whether later life can change the meaning of an earlier episode.

## The arc of the question

The project follows one progression. Each stage is only meaningful if the one before it holds.

**Experience → Persistent State → Future Behavior → Retrospective Revaluation**

| | stage | the question | where it stands |
|---|---|---|---|
| I | **Experience** | Can an agent build up a history of its own, with consequences, in a world that never tells it what matters? | Shown in constrained simulated worlds |
| II | **Persistent State** | Can that history be kept in a form that belongs to the agent and can be inspected, restored, moved or erased? | Shown for text records and for a learned memory |
| III | **Future Behavior** | Does the kept history change what the agent does later? | Depends on the representation and the task. A learned memory improved later decisions in one world type. In the configurations tested, text records changed choices through recognition and imitation, not through what the outcomes had been |
| IV | **Retrospective Revaluation** | Can a later experience change how an unchanged earlier episode shapes behavior? | Not tested. It needs a history-specific influence that has not yet been found |

Between III and IV sits the question the project was founded on: whether a *specific, personal* history, rather than familiarity, recency or position in a list, shapes later discretionary choices. It has not been shown.

## What this repository is

This repository is a public description of a research program. It is not the program itself. It contains no source code, model weights, prompts, raw outputs, logs or internal ledgers. A detailed private research record is kept separately and is not published here (see [DISCLOSURE.md](DISCLOSURE.md)).

The words *memory*, *experience* and *lived* are used functionally. A *lived* history means the agent's own choices had consequences inside a simulated world. *Memory* means stored records or a learned state. None of these words is a claim about feeling, consciousness or inner life.
